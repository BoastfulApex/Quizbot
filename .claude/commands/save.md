# /save buyrug'i

## Nima qiladi
1. `D:/ObsidianVault/QuizBot/logs/YYYY-MM-DD.md` fayliga bugungi sessiya logini qo'shadi.
2. `D:/ObsidianVault/QuizBot/_holat.md` ni joriy holat bilan yangilaydi.

## Sessiya logi formati (`logs/YYYY-MM-DD.md`)
```markdown
## HH:MM — <qisqa sarlavha>

**Bajarildi:**
- <1-3 ta asosiy ish>

**Fayllar:**
- `<fayl yo'li>` — <nima o'zgardi>

**Muammolar / eslatmalar:**
- <ixtiyoriy>
```

## `_holat.md` yangilash tartibi
- `yangilandi:` satridagi sanani bugungi sana bilan almashtiring.
- **Tayyor** bo'limiga yangi bajarilgan ishlarni qo'shing.
- **Qolgan ishlar** bo'limidan bajarilgan bandlarni olib tashlang.
- **Ma'lum muammolar** bo'limini yangilang (yangi muammolar qo'shing, hal qilinganlarni olib tashlang).
